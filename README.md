# rat.nix/Open5GS.nix

This module allows the declarative configuration of Open5GS in NixOS.

A custom option search for the module can be found on [rat-nix.github.io/open5gs.nix](https://rat-nix.github.io/open5gs.nix/)
or as 3rd-party Flake on [search.nixos.org](https://search.nixos.org/flakes?type=options&query=services.open5gs).

This project is in an early stage of development!
